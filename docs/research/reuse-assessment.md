Research performed 2026-10-21–22; no candidate installed, executed, benchmarked or security-certified. Local baseline `b835974491890e7bad8a2193643f5217686e5cdf`. Source snapshots, release observations and retrieval limitations are recorded in [upstream evidence](upstream-evidence.md). [Architecture comparison](architecture-options.md) applies the same U1–U7 cases to competing foundations.

## Evidence and scoring method

**V / verified** means the cited source implements the narrow stated feature or the official documentation explicitly establishes it. **P / partially verified** means only some relevant paths or behavior were traced. **U / unsupported** means the inspected interface does not provide the needed domain behavior or conflicts with it; it is not a universal claim that no extension could exist. **? / unknown** means evidence unavailable or no sufficient proof. Security correctness is never V merely because a permission function exists.

Fit scores: **0** conflicts with the responsibility; **1** large mismatch; **2** reusable with substantial adaptation; **3** strong narrow fit. Numbers are analyst judgments, not measured performance or feature counts. Each cell has fit/evidence status. Score confidence and code-avoidance estimates are qualitative; no fabricated LOC, capacity or maintenance-hour claims. A higher retrieval score cannot compensate for failing canonical ownership or governance.

### E01 Basic Memory

Inspected commit `8df7e90441e353d8ef88454d72e8d0a775e880f1`. [EntityService](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/services/entity_service.py) includes create/update/edit/move/delete paths that call FileService. It is a working knowledge application, not a drop-in passive policy evaluator. Native mutation against our canonical writable vault would bypass custom Proposal/Membership/disposal guards unless every path is constrained externally. Avoid relying solely on hiding MCP write tools: constrain OS access and network/service entry points.

[Watcher](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/index/watch_service.py) and [project-local orchestration](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/index/local_watch.py) establish reusable file-event infrastructure. Its project scope is useful, but authorization of every retrieval/history/edge/count path for our principals is unverified.

[Markdown parser](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/markdown/entity_parser.py) and [relation plugin](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/markdown/plugins.py) implement note/observation/link-derived graph semantics. Current branch [accepted-content endpoint](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/api/v2/routers/accepted_content_router.py) hydrates bounded accepted note content; [scoped search](https://github.com/basicmachines-co/basic-memory/blob/8df7e90441e353d8ef88454d72e8d0a775e880f1/src/basic_memory/api/v2/routers/scoped_search_router.py) accepts explicit project sets and delegates authorization resolution. ### E03 Graphiti

At `8e320f880e7d169a907dbf2a7ac4188586c03b55`, [Graphiti implementation](https://github.com/getzep/graphiti/blob/8e320f880e7d169a907dbf2a7ac4188586c03b55/graphiti_core/graphiti.py) performs episode ingestion, graph operations and model-backed extraction/retrieval. ### E06 Casbin and Python

[PyCasbin CoreEnforcer](https://github.com/apache/casbin-pycasbin/blob/master/casbin/core_enforcer.py), [ABAC example](https://github.com/apache/casbin-pycasbin/blob/master/examples/abac_model.conf), [allow-and-deny model](https://github.com/apache/casbin-pycasbin/blob/master/examples/rbac_with_deny_model.conf) and [enforcer tests](https://github.com/apache/casbin-pycasbin/blob/master/tests/test_enforcer.py) show configurable matcher/effect evaluation. The deny model requires an allow and absence of deny. Explicit model selection is essential; do not assume every Casbin model is deny-overrides. Source also allows enforcement to be disabled: application bootstrap must fail closed rather than exposing that switch to agents.

ABAC can evaluate resource ownership/attributes, conditions and cluster-domain grants; Core must supply verified facts and bounded approved model/functions. [Official ABAC docs](https://casbin.apache.org/docs/abac/). A Relation requires conjunction of edge/source/target decisions; no evaluator automatically implements query prefiltering, hidden counts, history visibility, Owner recovery or atomic grant changes with Git. Model test cases must cover time/session expiry, partial order, protected Node overrides, default deny and policy reload/cache invalidation. Avoid agent-authored expressions or a new universal policy language.

[Python metadata](https://github.com/apache/casbin-pycasbin/blob/master/pyproject.toml) reports 2.6.1, [requirements](https://github.com/apache/casbin-pycasbin/blob/master/requirements.txt) simpleeval/wcmatch; [license](https://github.com/apache/casbin-pycasbin/blob/master/LICENSE) Apache-2.0. The [release page](https://github.com/apache/casbin-pycasbin/releases) separately showed v2.8.0: retrieved source metadata and release mapping disagree and must be reconciled at the chosen immutable pin. API resolution was rate-limited; source hashes in ledger preserve retrieved bytes. Go [v3.11.0](https://github.com/apache/casbin/releases/tag/v3.11.0) is not a Python compatibility guarantee. [Transaction consistency discussion #1702](https://github.com/apache/casbin/issues/1702) reinforces that evaluator policy storage is not automatically our multi-store transaction. **Prototype policy model in P03; reuse evaluator if it saves code versus small explicit policy rules.**

### E10 Focused reuse: SQLite FTS5 and existing contract stack

[FTS5 reference](https://www.sqlite.org/fts5.html) documents lexical queries, tokenizers, external-content tables and rebuild commands. Core still owns index generation, authorization before ranking/counts and exact Revision mapping; global corpus scoring can leak hidden-content influence, so evaluate only authorized scope or isolated partitions. A final result filter alone is inadequate.

Preserve existing jsonschema/Ajv/Pydantic/code-generator/TS toolchain; its local tests already exercise real fixtures. Markdown-it-py/frontmatter/watch libraries are plausible parser/watcher reuse visible in BM metadata, but **not separately evaluated candidates** here: strict YAML/duplicate-key/body preservation must precede selection. Do not add transaction/outbox/Git libraries simply to fill a list; no inspected library has established our cross-Git/control/editor recovery semantics.
