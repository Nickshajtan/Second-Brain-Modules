## ADR disposition

ADR-001 JSON Schema, ADR-002 Python/TS, ADR-003 independent generation/validation, ADR-004 application enforcement and ADR-005 optional HTTP remain compatible. Their packaging/version specifics remain proposals, not newly verified upstream claims. ADR-006 is partially superseded only for embedded Relations; its unproven recovery remains open. ADR-007 monolith and ADR-008 isolated whole-repository reuse remain compatible; Core context/workflow scope in associated documents is narrowed by ADR-009. All eight ADRs and the ADR index were read. No historical ADR was overwritten.

## Toolchain observed

`tools/generate_contracts.py` invokes existing generators into a temporary tree and compares full file set/hashes; `tools/generate_typescript.mjs` disables HTTP reference resolution. Python example validation and Ajv2020 validate independently; `tests/test_contract_spike.py` covers the shared 24-case corpus, generated round trips and Python/TS verdict parity. `tests/test_example_validation.py` covers offline refs, link safety, duplicate keys, intended-negative reasons and CLI diagnostics. `.github/workflows/ci.yml` defines Windows/macOS/Linux checks. These tests prove illustrative contracts, **not** authorization, recovery or Obsidian integration. Execution evidence is in [summary](../research/README.md).
