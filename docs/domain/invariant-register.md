# Current invariant register — M1.2

Stable I01–I21 retain their established identities. Each row maps relevant
[Owner requirements](accepted-decisions.md) to canonical structures and actual
runtime limits. Requirement ranges are inclusive within their named group.
The [coverage matrix](../contracts/contract-coverage-matrix.md) identifies individual
operations and deferrals; naming a schema does not establish semantic enforcement.

Schema keys below resolve under the exact namespace
`https://github.com/Nickshajtan/Second-Brain-Modules/contracts/1.0.0/`:
**C** = `common.schema.json`, **K** = `knowledge.schema.json`, **O** =
`operations.schema.json`, **G** = `governance.schema.json`, **P** =
`control.schema.json`, **S** = `snapshots.schema.json`, **A** =
`authoring.schema.json`, **T** = `transaction.schema.json`.
All references are JSON Schema `$defs` paths. The [registry](../../contracts/registry/v1.json)
remains structural authority; these descriptions define semantic obligations.
