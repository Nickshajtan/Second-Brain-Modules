## Authority reconciliation

M12-CORE-10/11 supersede filesystem-projection alternatives in historical I19/D01. M12-REL-01/04 supersede embedded Relation assumptions. M12-TXN-08/09 supersede the mandatory separate-journal/four-PoC gating proposal; a Git ref alone does not promise physical flush durability. M12-GOV-12 confirms minimum Node selection; O2 concerns Relation assertion breadth. M12-TXN-14 excludes Core workflow/subscription execution while permitting externally delivered scoped facts. No new ADR is required: these consolidate Owner decisions under ADR-009/010 rather than select a new architecture.

The preferred native Relation/Collection note representation is a confirmed direction, not a delivered adapter or a permission model. Admission-on-create semantics are confirmed; the current trusted `membership.admit` grant is a bounded M1 implementation, not a final external capability spelling.
